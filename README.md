# PickMyDoc

## Description
PickMyDoc est une application de bureau permettant aux patients de rechercher des médecins et de gérer leurs rendez-vous médicaux.

## Objectifs
- Rechercher des médecins par nom, spécialité et ville.
- Réserver un rendez-vous médical.
- Consulter ses rendez-vous.
- Modifier ou annuler un rendez-vous.

## Technologies utilisées
- **Python** : logique de l'application.
- **Tkinter** : interface graphique.
- **SQLite** : base de données.

## Équipe
Projet réalisé dans le cadre du module Python avancé.

## État du projet
